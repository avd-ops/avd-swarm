# avd-swarm

A chat front end for operating the [AVD landing zone](https://github.com/nickprignano/avd-landing-zone) from any browser, iPad included. A coordinator agent hands questions to specialist agents (cost, hosts, images, access). They read through the operations brain's tools and change Azure only through brain plans that a person approves in a GitHub Environment.

This is the development version of the pattern. Once it has a record of approved, verified runs, it moves tenant-wide into [tenant-swarm](https://github.com/nickprignano/tenant-swarm).
