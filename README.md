# avd-swarm

A chat front end for running AVD estates, built on the [AVD landing zone](https://github.com/nickprignano/avd-landing-zone), from any browser, iPad included. A coordinator agent hands questions to specialist agents (readiness, deploy, hosts, images, users, cost). They read freely and change nothing without a person approving the exact plan. It connects to the [second brain](https://github.com/nickprignano/avd-second-brain) where they overlap.

This is the development version of the pattern. Once it has a record of approved, verified runs, it moves tenant-wide into [tenant-swarm](https://github.com/nickprignano/tenant-swarm).
